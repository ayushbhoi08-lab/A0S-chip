# Ansh-108 Core — Yuga Mapping LUT (Mahāyuga → 108-state loop)

*Config record. Derivation + BRAM init table. Files: `scratchpad/yuga_lut.coe`

Created 2026-06-24.*

## Derivation (integer-exact)

```
V    (Vipala, resolution)   = 0.016 s          [user spec; canonical vipala = 0.4 s]
Y    (Julian year)          = 365.25 × 86400   = 31,557,600 s
MY   (Mahāyuga)             = 4,320,000 yr
S    (loop states)          = 108
f_clk                       = 157,900,000 Hz   [measured routed fmax, Phase 4]

T_MY   = MY × Y             = 136,328,832,000,000 s
N_tot  = T_MY / V           = 8,520,552,000,000,000 Vipalas      → 53-bit counter
K_state (YUGA STEP)         = N_tot / 108 = 78,894,000,000,000 Vipalas/state
                            = 40,000 yr/state                    (exact, integer)

YUGA STEP  = 0x000047C0F0D84C00   (64-bit)
N_tot      = 0x001E45659B401000   (= LUT wrap value, state 108≡0)
```

### Real-time driver (NCO phase increment, optional)
```
rate            = 1/V = 62.5 Vipalas/s
inc/clk         = 62.5 / f_clk          (fixed-point, F fractional bits)
clocks/Mahāyuga = T_MY × f_clk = 2.1526e22  (~2^74.2)
F_req (<1 Vipala drift over a full Mahāyuga) = 75 frac bits
   F=40 : K_inc = 0x6A409
   F=64 : K_inc = 0x6A408D87FC8
   F=75 : K_inc = 0x352046C3FE4312
// physical bound: a crystal f_clk at ±20 ppm drifts ±2.7e9 s over a Mahāyuga
//   >> 0.016 s, so the LUT is exact but real accuracy is clock-source-limited.
```
